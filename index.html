How long people wait here

There is a queue here that everybody joins and nobody measures. This site is an attempt to measure it honestly: how long people really wait, where it is worst, and what the numbers still cannot tell us.

How the data was collected

  • I stood in these queues myself with a watch, at different hours of the day, and wrote one row per wait into data/observations.csv.
  • Each row records the place, the date, the queue length and how long the person I followed waited. 0 rows exist so far, across 0 known places.
  • Photos back up the rows that cite them, and the rows behind every chart are printed underneath it, so a reader can check any number against the file it came from.
